# FoodSafe C Data Structures

This preserved C implementation demonstrates the course-level data structures behind FoodSafe: linked list, hash table, min heap, priority queue, searching, sorting, restaurant/inventory/complaint models and storage.

Build with GCC:

```text
make
```

Run the demo executable:

```text
foodsafe.exe
```

On Linux/macOS the generated binary is `foodsafe`. The web application does not depend on the C executable at runtime; this keeps the Windows Flask demo reliable while retaining the C implementation for DS evaluation.
